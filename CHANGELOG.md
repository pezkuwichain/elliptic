# [6.6.2](https://github.com/pezkuwichain/elliptic/releases/tag/v6.6.2) (@pezkuwi/elliptic)

- Security: the RFC 6979 nonce is computed as `bits2int(T)` over all `rlen` bytes of the HMAC-DRBG output `T`. The output used to be converted to a `BN` before truncation, which dropped its leading zero bytes, so the shift that removes the bits beyond `qlen` was computed from a shorter length. On curves whose order is not a whole number of bytes (P-521: 521 bits in 66 bytes) every nonce candidate starting with a zero byte, about 1 in 256 signatures, was left unshifted, the signature differed from RFC 6979 and, paired with a correct signature of the same message, exposed the private key (CVE-2025-14505, GHSA-848j-6mx2-7j84). Curves whose order fills its bytes (secp256k1, P-192, P-224, P-256, P-384) never shifted the nonce, so their signatures are unchanged.
- Dependencies: `bn.js` is required at `^4.12.3`, the first release without the infinite loop of GHSA-378v-28hj-76wf.
- Tests: signatures on secp256k1, P-256, P-384 and P-521 are compared with `@noble/curves`, over random keys and over cases whose first nonce candidate starts with a zero byte.
- Tooling: tests run on mocha 12 and lint on eslint 8; the Grunt, Istanbul, Coveralls and Sauce Labs tooling, the prebuilt `dist/` browser bundle (unpublished, and built from the unfixed code) and the `benchmarks/` harness (it pinned `secp256k1` 0.0.x, GHSA-584q-6j8j-r5pm, and a `git://` dependency GitHub no longer serves) are removed. CI runs on GitHub Actions.
- Published as `@pezkuwi/elliptic`, a fork of indutny/elliptic.
